# 🎬 Visual Loop — Product Requirements Document (PRD)

## 📘 Project Overview
**Visual Loop** (placeholder name) is a professional videography and post-production studio specializing in **cinematic storytelling, music videos, short films, commercials, and event highlights**.  
The team provides full-cycle production — from pre-production planning and on-set cinematography to editing, color grading, and sound design.

This website will serve as a **digital portfolio and lead-generation platform**, highlighting the studio’s creative work and technical expertise.

---

## 🎯 Goals
- Showcase the studio’s **visual storytelling** and **completed projects**.
- Communicate professionalism, creativity, and emotion-driven visuals.
- Offer a **smooth, cinematic user experience** with responsive design.
- Optimize for **SEO** and **WCAG 2.1 accessibility standards**.
- Built with **React + TypeScript + ShadCN + TailwindCSS**, following **MCP (Modular Component Pattern)**.

---

## 🧩 Core Website Structure
1. **Home Page**
   - Cinematic hero section (video reel background)
   - Tagline: *“Crafting Stories in Motion”*
   - CTA: “Watch Showreel” / “Book a Shoot”

2. **About Page**
   - Studio overview + team introduction
   - Philosophy: *“Emotion, precision, and storytelling in every frame.”*

3. **Portfolio Page**
   - Grid/list of completed projects (10+ items)
   - Each card: thumbnail, title, client, genre, brief description
   - Filter by category (e.g., Music Videos, Commercials, Films)
   - Lightbox modal for embedded video player

4. **Services Page**
   - Pre-production
   - Cinematography
   - Post-production (Editing, Color Grading, Sound)
   - CTA: *“Request a Quote”*

5. **Testimonials Page**
   - Client feedback and ratings

6. **Contact Page**
   - Inquiry form
   - Social links
   - Studio contact info

7. **Footer**
   - Navigation + Copyright
   - Social icons
   - “Made with ❤️ by Visual Loop”

## 🧠 Design & UX Guidelines
- **Theme:** Cinematic, modern, dark aesthetic  
- **Typography:** Large cinematic headings, clean sans-serif body  
- **Animations:** Smooth fade/slide transitions (Framer Motion optional)  
- **Responsiveness:** Mobile → Tablet → Desktop  
- **Accessibility:**  
  - Minimum contrast ratio 4.5:1  
  - Keyboard navigation  
  - ARIA labels  
  - Alt text for media
